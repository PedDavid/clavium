{# Expiry selector shared by the rotate and record dialogs. Expects: expiry_id (id of the date input), expiry_default ("match" or "never"), expiry_base (id of a date input the relative choices count from, or "" for today). Without JavaScript only the date input shows; app.js reveals the rest and writes the resolved date into that input, which is what the server reads. #}

Days, weeks, months or years: 45d, 10w, 8mo, 2y.
